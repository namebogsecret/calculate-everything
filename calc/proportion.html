Пропорция

Proportion

a / b = c / x — найти x.

Введите a, b, c.

Как это работает

Из пропорции a/b = c/x неизвестное находится перекрёстным умножением: x = b·c/a.

Что это и что показывает

Пропорция — это равенство двух отношений: a / b = c / x. Она говорит, что величины меняются согласованно: во сколько раз больше одно, во столько же больше другое. Калькулятор находит неизвестный член пропорции — приём, который решает огромный пласт задач на масштаб, скорость, рецепты и цены.

Формула и откуда она

Из a / b = c / x неизвестное находится перекрёстным умножением: a · x = b · c, откуда x = b · c / a.

Почему «крест-накрест»? Умножим обе части равенства на b · x — знаменатели сократятся, и получится a · x = c · b. Это главное свойство пропорции: произведение крайних членов равно произведению средних.

Как посчитать вручную (по шагам)

  1. Запишите пропорцию так, чтобы одинаковые по смыслу величины стояли друг под другом.
  2. Перемножьте крест-накрест известные члены.
  3. Разделите полученное произведение на оставшийся известный член.
  4. Результат — искомое x.
  5. Проверьте: подставьте x и убедитесь, что оба отношения равны.

Разбор примера

Если 4 кг яблок стоят 360 рублей, сколько стоят 7 кг? Составим пропорцию 4 / 360 = 7 / x.

Перекрёстное умножение: 4 · x = 360 · 7 = 2520, значит x = 2520 / 4 = 630 рублей.

Проверка: 360 / 4 = 90 руб/кг и 630 / 7 = 90 руб/кг — цена за кг одинакова ✓.

Где применяется

Пропорции — рабочая лошадка прикладной математики: масштаб карт и чертежей, пересчёт рецептов, валютные курсы, концентрации растворов, задачи на движение. В ОГЭ и ЕГЭ это задачи на проценты, смеси и прямую/обратную пропорциональность. В IB и SAT — ratio and proportion, unit rates, scale factors. Понимание, какие величины ставить «друг под друга», важнее самой арифметики.

Частые ошибки

  • Перепутывают порядок величин — записывают 4 / 360 = x / 7 вместо 4 / 360 = 7 / x.
  • Применяют прямую пропорцию там, где зависимость обратная (чем больше рабочих — тем меньше времени).
  • Делят на неверный член после перекрёстного умножения.
  • Смешивают разные единицы измерения (кг и граммы) в одном отношении.
